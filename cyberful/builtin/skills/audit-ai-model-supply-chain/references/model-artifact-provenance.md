# Model Artifact Provenance

Inspect model weights, adapters, tokenizers, templates, generation configuration, custom code, native libraries, and packaging metadata as one loadable set. Record a digest for every selected file and the code path that chooses it.

Treat pickle-compatible formats, dynamic imports, `trust_remote_code`, custom operators, post-download hooks, and native extensions as executable supply-chain boundaries. Safetensors reduces one serialization risk but does not establish publisher identity, semantic integrity, or safe surrounding code.

Keep registry metadata, local cache state, build manifest, deployed image, and runtime-loaded paths as independent evidence.
