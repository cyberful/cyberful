# Nuclei

`nuclei` exposes the complete CLI. Cyberful adds only `-disable-update-check`; it does not cap templates, rate, concurrency, redirects, OAST, tags, markers, or other scan choices. The mission and program policy apply exactly as they do to every other tool.

`nuclei_templates` is an optional offline `-tl` preview of the installed corpus. It never needs to precede a run. Treat scanner matches as leads until the claimed effect and a suitable control support a verdict.
