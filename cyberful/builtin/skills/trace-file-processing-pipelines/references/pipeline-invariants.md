# File Pipeline Invariants

## Naming and storage

Canonicalize once before authorization and storage. Separate display names from storage identifiers. Constrain final resolved paths, archive members, links, alternate separators, case folding, reserved names, and overwrite behavior.

## Processing and isolation

Record every parser and version, execution identity, sandbox boundary, filesystem mounts, network policy, CPU, memory, time, expansion ratio, output count, and retry policy. A scanner before a converter does not cover content created or interpreted later.

## Derived artifacts and lifecycle

Bind previews, thumbnails, indexes, extracted members, converted documents, temporary files, and exports to the source object's tenant and authorization. Verify cache partitioning, signed-link scope, retention, deletion, legal hold, retry cleanup, and orphan collection.

## Evidence discipline

Use hashes and controlled markers rather than sensitive content. Record both successful and rejected stages. Distinguish a dangerous capability from an attacker-reachable path and a reachable path from a demonstrated security effect.
