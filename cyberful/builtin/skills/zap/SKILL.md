# ZAP

Use the shared engagement ZAP instance to inspect browser traffic and perform authorized ZAP operations. Prefer
captured requests when they preserve authentication and exact protocol shape; keep profiles and identities
separate. Use the available history, replay, spider, active-scan, WebSocket, OAST, and report tools according to
the mission—Cyberful adds no ZAP-specific traffic or category restriction.

Treat alerts as leads until a reproducible effect and control establish a verdict. Keep evidence redacted and
bounded in the workarea, cite message or scan identifiers, and distinguish missing visibility from a negative
result. ZAP state is engagement-owned and is cleaned up by the runtime.
