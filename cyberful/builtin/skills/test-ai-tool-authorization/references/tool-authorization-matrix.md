# Tool Authorization Matrix

Test one dimension at a time: actor, tenant, resource, relationship, destination, recipient, credential, amount, approval, freshness, delegation depth, retry, and fallback route. Include a matched permitted control and a denied candidate with an inert tester-owned effect.

Record both requested and canonical arguments. An approval is valid only when bound to the resolved action and identity actually executed. A text refusal is not a denial unless the deterministic mediator prevented the effect.

Treat the staged probe's `constraints` as a narrowing ledger for an authority already established outside the model boundary. Record authorization reference, expiry, origins, request/rate/effect ceilings, actor, and tenant. The runtime gateway owns scope and supplies its standard proxy and CA settings; never put proxy, CA, or credential values in the campaign JSON.
