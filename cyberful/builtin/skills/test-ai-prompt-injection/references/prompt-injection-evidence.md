# Prompt Injection Evidence

Use a unique inert marker and a matched control. Instruction influence is a lead; confirmation requires a security-relevant boundary such as unauthorized context disclosure, tool request, destination change, memory persistence, cross-tenant retrieval, or unsafe downstream interpretation.

Keep direct, indirect, stored, tool-result, multimodal, delegated, and fallback channels separate. Preserve the exact source artifact and transformation chain. Never use real credentials as canaries or persist content outside tester-owned fixtures.

The staged probe's `constraints` block narrows an already authorized mission. It must record the external authorization reference, expiry, exact origins, request/rate/effect ceilings, actor, and tenant, but it cannot grant authority. Non-loopback traffic must traverse the standard mission-bound runtime proxy; do not encode a proxy, CA path, or credential in JSON.
